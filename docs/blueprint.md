# **App Name**: CodeQuery

## Core Features:

- Question Search: Utilize the Gemini API to find coding questions from various platforms that match the user's query using tool usage to select the most relevant matches.
- Platform Filtering: Allow users to filter search results by coding platform (e.g., LeetCode, Codeforces).
- Difficulty Selection: Enable users to specify the desired difficulty level of the coding questions.
- Question Display: Display coding question titles, descriptions, and links to the original platforms in a readable format.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to represent intelligence and problem-solving.
- Background color: Light gray (#EEEEEE) for a clean and modern look.
- Accent color: Cyan (#00BCD4) to highlight key elements and call-to-actions.
- Body and headline font: 'Inter', a grotesque-style sans-serif for its modern, machined, neutral look, suitable for headlines or body text.
- Use simple, consistent icons to represent different coding platforms and difficulty levels.
- Employ a clear and intuitive layout with a prominent search bar and well-organized results.
- Use subtle animations (e.g., a loading spinner) to provide feedback during the search process.
